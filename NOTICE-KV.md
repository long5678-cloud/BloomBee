# KV integration provenance and licenses

The original BloomBee LICENSE is preserved. This integration extends the existing BloomBee fork rather than creating a separate unrelated project.

The local native bridge calls the official LMCache API; official LMCache source is not vendored here. The selected source is LMCache v0.5.7, commit `236f3eec32a2d330662a1795d90a01a1e0782c49`. Its upstream license and notices apply when that dependency is installed. Adapter code, candidate qualification and LRFU/transition selection are BloomBee-side implementations; they are not advertised as built-in LMCache predictors.

Dynamo-derived retention adapts the documented/audited behavior subset of NVIDIA Dynamo KVBM v1.6.2, commit `28f9765d98ded77149a94d0defee6d54e97f6741`, with GPU return/priority behavior audited against TensorRT-LLM v1.3.0rc29. It does not include the full Rust/NIXL runtime, native pinned allocator, async transfer or all tiers. The native vendor source trees remain outside this review checkout. Existing historical research option provenance remains in its source and internal records.

The Hivemind dependency uses its own upstream license and source. Model weights, tokenizer assets and external coding trace are not included in this checkout. Small test fixtures contain recorded cache identity metadata; CPU tensor values generated by tests are deterministic fixtures, not original model KV or user code text.
