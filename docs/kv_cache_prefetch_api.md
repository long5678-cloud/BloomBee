# Legacy Prefetch API

The inherited `bloombee.kv_cache.prefetch.Prefetcher` and `examples/kv_cache_prefetch.py` are the earlier CPU/loopback path. They remain available for compatibility. They are not the final official LMCache-backed ordinary model path. Use [the current API](kv-network-api.md) and [ordinary runtime](ordinary-runtime.md) for the current two strategies and native bridge.
