# Telemetry API

Use [the current telemetry contract](kv-network-api.md#telemetry). The stable `Event`, `PublisherRef`, `Telemetry`, `query` and `IncompleteTelemetry` imports are preserved. The native generation adapter and ordinary PagedTelemetry adapter share one exact-window statistical implementation. See [validation](validation.md) for current CPU results and historical real-model evidence.
